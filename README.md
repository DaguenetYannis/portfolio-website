# Analytical Portfolio

A calm, dark-mode-first portfolio built with Astro for institutional policy analysis and research.

## Stack

- **Framework**: Astro (static-first)
- **Language**: TypeScript
- **Styling**: CSS Variables
- **Deployment**: Static hosting
- **Database**: None
- **Backend**: None

## Development

```bash
npm install
npm run dev      # Start dev server
npm run build    # Build for production
npm run preview  # Preview production build
```

## Project Structure

See `PORTFOLIO_BRIEF.md` for detailed architecture overview.

## Architecture

- `/public` - Static assets and outputs
- `/src/components` - Reusable UI components
- `/src/pages` - Page routes
- `/src/styles` - Global styles and design tokens
- `/src/content` - Project content and metadata
- `/src/data` - Data files (projects, metadata)
- `/src/layouts` - Page layout templates

## Philosophy

- Dark mode first (respects system preferences)
- Institutional aesthetic
- Performance optimized
- Extensible component structure
- Static generation for reliability
